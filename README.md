# My Portfolio Website

A personal portfolio website built with HTML and CSS, showcasing my projects, skills, and experience.

## 🔍 Goals for my Portfolio

1. Present Technical Expertise
2. Showcase Software Engineering Knowledge
3. Share My Personal Brand
4. Demonstrate Projects
5. Encourage Communication
6. Keep Portfolio Up to Date
7. Showcase Achievements
8. Ensure Responsive Design

## 🚀 Project Structure

```
MyPortfolio-HTML-CSS/
├── assets/          # Contains images and other media files
├── css/             # Stylesheets for the website
├── lib/             # External libraries and dependencies
└── index.html       # Main HTML file
```

## 🌿 Branches

This project has two main branches:

1. **main** - The production-ready version of the website
2. **style** - Branch for styling and design improvements

## 🛠️ Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/TharuSenevirathne/MyPortfolio-HTML-CSS.git
   ```

2. Open `index.html` in your preferred web browser to view the website locally.
